# MayOS 0.5.4-pre20 · 文件、编辑与更新流程

- 文件管理器支持复制目录树和导入离线文件包。适用的 GPT MayFS 数据区支持 96 个条目和单文件 32,767 字节。旧快照保留，旧裸盘继续使用其原格式。
- 编辑器支持光标移动、选区、剪切、复制、粘贴、撤销和重做。保存和切换文档会处理未提交的输入法文字与未保存的改动。
- 设置可从 GitHub 查看版本、发布时间、大小、架构、内核与更新摘要。Linux Live 代码可下载固定 Git 提交中的 ISO，显示下载进度并校验 SHA-256。安装媒体显示实际写入和回读校验的阶段进度。
- MayKernel Explorer 通过原生 HTTP 读取纯文本和简化 HTML 预览。HTTPS 要求受信任的时间与证书。网页脚本和完整排版暂未支持。
- MayKernel 声音设置控制 Intel HDA 输出增益；有兼容 ALSA 控件的 Linux 可调整输出音量。MayKernel 在 GRUB 选择分辨率，Linux 可尝试切换驱动公布的模式。
- 独立安装 ISO 只安装 MayKernel64。已有 MayKernel 安装应从安装介质启动，写入空闲槽位，经试启动后确认；同时保留原槽和用户数据。
- QEMU 覆盖旧版 4Kn 迁移、冷启动与断电恢复、安装介质试启动及回退、编辑、文件导入与复制、原生 Explorer 和 HDA。实际显示器兼容性仍需在实体机上验证。
