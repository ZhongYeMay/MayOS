# MayOS 0.5.4-pre7 · MayKernel64 CA 与可信时间

- 原生 TLS 接入 118 个 Mozilla 公共 CA 根证书。证书包以 SHA-256 固定，握手继续检查主机名和证书有效期。
- 内核可验证 Ed25519 签名的 UTC。每次签名绑定一次性的 RDSEED 随机挑战，时间验签后由内核定时器推进。
- BIOS 和 x86_64 UEFI 可共用这张 MayKernel64 ISO。公开镜像包含 CA 根证书。部署者需自行配置时间公钥，并在每次启动后完成时间验签。未取得可信时间时，公网 TLS 保持关闭。
- QEMU 验证覆盖签名 UTC、旧挑战、时间回拨、私有 CA 拒绝，以及已验证的本地 TLS 链路。公网 Bing 自动刷新仍待验证和接入。

时间机构的配置步骤见同目录 README。
