# MayOS 0.5.2 多语言系统设计

0.5.2 的交付范围是 MayKernel64 的多语言安装器、首次开机、桌面和系统应用。安装介质必须包含所有首发语言所需的资源，允许离线安装、选语言和进入桌面。Linux64 路线在 MayKernel64 验收后复用协议和语言资源。

## 首发语言

首发目标为 31 种语言、39 个 BCP 47 地区设置。每种语言都需要覆盖首发系统界面。地区变体共用适用的译文，并独立定义日期、数字及默认输入布局。

| 范围 | 语言和地区代码 | 数量 |
| --- | --- | ---: |
| 全球通用 | 英语 `en-US`、`en-GB`，西班牙语 `es-ES`、`es-419`，葡萄牙语 `pt-BR`、`pt-PT`，法语 `fr-FR`、`fr-CA` | 8 |
| 欧洲 | 德语 `de-DE`、意大利语 `it-IT`、荷兰语 `nl-NL`、波兰语 `pl-PL`、俄语 `ru-RU`、乌克兰语 `uk-UA`、土耳其语 `tr-TR` | 7 |
| 东亚 | 简体中文 `zh-Hans-CN`、繁体中文 `zh-Hant-TW`、香港繁体中文 `zh-Hant-HK`、日语 `ja-JP`、韩语 `ko-KR` | 5 |
| 东南亚 | 印度尼西亚语 `id-ID`、越南语 `vi-VN`、泰语 `th-TH`、菲律宾语 `fil-PH`、马来语 `ms-MY` | 5 |
| 南亚 | 印地语 `hi-IN`、孟加拉语 `bn-BD`、乌尔都语 `ur-PK`、泰米尔语 `ta-IN`、泰卢固语 `te-IN`、马拉地语 `mr-IN`、古吉拉特语 `gu-IN`、旁遮普语 `pa-Guru-IN`、`pa-Arab-PK` | 9 |

## 安装与切换体验

- 安装器在欢迎页提供语言入口。首屏同时显示各语言的本名和当前界面语言中的名称，支持键盘搜索、方向键、鼠标和确认预览。首选简体中文和英语可直接从顶部进入，其他语言按书写系统分组。
- OOBE 保留七步。语言页设在软件许可前，确认后立即切换后续页面。首次安装从目标盘读取安装器选定的初始语言，用户仍可在 OOBE 更改。各语言展示相应的许可说明，提供完整的英文 MIT 原文。
- 设置增加 **语言与地区**。显示语言、地区格式与输入源分别设置。预览后可确认或撤销，确认即刷新菜单、设置、文件管理器、更新面板和系统对话框。语言切换只写入语言相关设置，时区、文件与编辑器使用各自的状态。
- 优先遵循已有选择。没有记录的新安装使用安装器传入的语言；直接启动和从 0.5.1 升级时使用延续现有中文界面的 `zh-Hans-CN`。语言资源缺失、损坏或地区标签未知时，按同语言同文字地区变体、语言默认地区、内置英语逐级回退。简体和繁体之间需由用户主动选择。
- RTL 页面使用前后方向布局。步骤栏、导航按钮、对齐和焦点顺序随文字方向调整，版本号、网址、磁盘路径、文件名和键盘快捷键作为独立文本片段排版。圆角、边框、黑灰配色及交互状态采用现有 MayOS 组件。

| 界面区域 | 布局 |
| --- | --- |
| 进度侧栏 | 使用 0.5.1 OOBE 的七步侧栏。当前步骤使用高亮卡片，已完成步骤保留状态标识。窄布局将侧栏收为顶部的当前步骤和总步数。 |
| 语言列表 | 一个可滚动面板，主行显示语言本名，副行显示地区和当前界面中的译名。选中状态同时用边框和勾标表示，长名称换行，搜索框支持按本名与译名筛选。 |
| 底部操作区 | 保持返回、预览和确认操作可见。较长语言使用随文本扩展的按钮，窄布局改为换行或纵向排列。预览页提供当前和目标语言都可识别的返回入口。 |

## 系统接入

| 层 | 设计 |
| --- | --- |
| 语言资源 | 以稳定消息 ID 建目录，源数据由构建器生成共享 C 表和离线语言包。消息条目声明参数名称、类型和复数形式；界面通过 `tr(id)` 和带类型的格式化入口取词。采用 CLDR 规则处理复数、日期、数字、字节单位和地区变体。构建时检查错漏、重复、占位符和非法 UTF-8。 |
| MayKernel | 从 `kernel/gui.c` 的 OOBE、顶栏、设置、文件管理器、编辑器和更新面板逐批提取硬编码文案；错误状态转换成稳定的消息 ID。品牌名称、MayShell 命令、串口自动化标记、机器可读版本及校验值保持固定，现有脚本仍可解析。 |
| 离线安装器 | `linux/installer-ui.c` 使用同一语言目录及文本布局规则。固定控件与运行结果通过状态码本地化；详细诊断仍可从串口读取。图形界面只向安装后端传递经过目录查表验证的语言标签。 |
| 写入与兼容 | 安装器完成空盘校验和镜像写入后，在新安装的 EFI 分区写入从目录映射得到的初始语言提示。GRUB 将其作为可选 Multiboot 参数传给 MayKernel，内核再次校验，仅供首次开机读取。离线升级从 MayFS 读取语言，安装器的本次选择只控制本次安装器界面。 |
| 持久化 | 在 MayFS 的常规文件表中保存版本化设置记录，并复用现有双快照同步。读取时验证标签和长度，未识别字段按默认值处理。现有 `MAYPREF1` 记录与语言文件独立，0.5.1 对常规文件的读写同时保留语言文件。 |
| 文字引擎 | 替换 `kernel/gui.c` 现有仅处理 1–3 字节的 UTF-8 解码和固定字符宽度。统一 UTF-8 校验、字素簇测量、换行、渲染及方向处理。按文字系统使用 OFL Noto 字体子集，CJK 根据地区选择字形。固定文案可在构建时用 HarfBuzz 和 FriBidi 排版，动态输入、文件名及混合方向内容使用可在裸机运行的排版后端。 |
| 键盘与输入 | 将 `kernel/core.c` 的 PS/2 扫描码解码与布局分离，使 USB HID 和 PS/2 共用按键事件。支持各语言布局、重音组合键和字素簇删除。中日韩需要离线组合输入，至少覆盖拼音、注音、仓颉、日语罗马字/假名转换和韩文组合；南亚与东南亚使用相应的原生文字布局。输入源切换不改变界面语言。 |

预排版和运行时文字渲染是不同的验证项目。构建机能正确显示字形，只能证明字体资源和构建侧排版可用。运行时后端应在 freestanding x86-64 构建中先验证内存、字体缓存和双向布局，再确认独立启动。

## 开发顺序与验收

| 阶段 | 完成条件 |
| --- | --- |
| 语言框架 | 构建生成 39 个地区目录项；中英真实文案贯通安装器、OOBE、桌面与设置；重启、A/B 试启动和回退保留语言。新构建的预发布标签按现有版本策略使用 `v0.5.2-preN`。 |
| 排版与输入 | 离线启动验证简繁中、日、韩、德、俄、阿拉伯语、希伯来语、乌尔都语、印地语、孟加拉语、泰语。覆盖长标签、换行、RTL 混合文本、字体回退、静态文案与动态输入、低分辨率和自动缩放。 |
| 全量译文 | 39 个地区设置均可选择。安装器、OOBE、桌面菜单、设置、文件管理器、编辑器和更新面板无缺失项与占位符错误；按各语言实际语境审核关键提示，并生成各语言的真实 QEMU 截图。旧版自动化串口输出兼容。 |
| 发布回归 | BIOS/UEFI ISO 启动、UEFI 新装、无光盘硬盘启动、断网访问语言资源、选错语言恢复、破损语言记录回退、MayFS 数据保护、升级与回退逐项通过。正常内存及低内存下测量字体缓存、首屏耗时和 ISO 大小后，才标记 0.5.2 正式发布。 |

截至本设计，已核对 0.5.1 中的 OOBE、MayFS 设置记录、安装器架构、固定宽度字形渲染及键盘入口。已使用构建机的 Noto、HarfBuzz 与 FriBidi 验证 16 组文字的样例覆盖与排版。系统界面翻译、裸机排版、离线输入和 QEMU 新语言矩阵属于上述实施与验收阶段。
