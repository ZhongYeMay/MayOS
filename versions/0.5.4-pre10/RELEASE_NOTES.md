# MayOS 0.5.4-pre10 · 统一视觉与字符画彩蛋

- 启动菜单、启动日志、安装界面、首次开机设置和桌面共用 MayOS 深色配色。
- 新建配置与恢复默认均使用 Microsoft Fluent UI System Icons 的白色箭头，经 MayOS 补充深色描边；保留黑色和自定义指针选项。
- MayShell 输入 ascii 打开字符画彩蛋，Esc 返回。原有 meow 彩蛋保留。
- GRUB 启动菜单从版本文件读取 MayOS Live 版本号。

安装介质进入图形安装器之前使用高对比度文字引导菜单，以保持固件显示兼容。QEMU 已验证 BIOS 取消安装不写盘，以及 UEFI 图形安装、回读校验、离线首次开机与文件跨冷启动保留。实体机仍按通用 x86_64 硬件矩阵验收。
