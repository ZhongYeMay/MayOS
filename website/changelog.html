MayOS 0.5.2：Live、双内核与安装器统一版本

MayKernel64、MayOS Live RAM-only、Linux64（7.3.1）与 0.5.2 离线安装器已整合。安装到空白虚拟硬盘的 MayKernel ELF 与 Live / 普通启动使用的 ELF SHA-256 完全一致；Live 已验证 BIOS/UEFI 不改变磁盘字节。

QEMU 八项测试全部通过；实体电脑与 USB 启动兼容性仍待进一步验证。Mission Center 正式移植不在本版本验收范围内。

Windows 鼠标指针

打开「设置 → 个性化 → 鼠标指针」，可预览、应用和恢复默认。支持静态 CUR 和动画 ANI，保留图像透明度、点击热点和文件定义的播放时序。

可选择文档中的 Cursor.cur、Cursor.ani 或 Cursor.ppm。超过 MayFS 单文件上限的 CUR 和 ANI 可用源码包中的 scripts/import_cursor.py 导入新镜像。

开发预览 · QEMU 实测

双内核任务管理器与 MayKernel /proc

MayKernel64 和 Linux64 的 Rust 任务管理器都提供 CPU、GPU、磁盘、内存与网络活动视图。Linux64 可读取驱动提供的 GPU 利用率。MayKernel64 和本次 QEMU 测试中的 Linux64 均显示实际帧缓冲提交频率。

MayKernel64 新增 Rust 编写的只读 /proc，可通过终端和文件管理器查看 CPU、内存、运行时间、磁盘、网络及内核信息。旧磁盘上的同名目录会保留。

首批八种界面语言

简体中文、繁體中文、英语、日语、韩语、西班牙语、法语和德语已接入 MayKernel64 的首次开机及桌面设置。可通过键盘或鼠标切换，MayFS 会保存已应用的选择。

已实测日语首次开机、法语设置和冷启动恢复。地区格式、输入法、RTL 排版及更多语言仍在开发范围内。
