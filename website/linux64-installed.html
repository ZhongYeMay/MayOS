按需安装 Firefox ESR

先启动已安装的 MayOS Linux64 硬盘系统。按 Ctrl+Alt+F2，登录本地账户并执行以下两条命令。

curl -fLo install-firefox \
  https://raw.githubusercontent.com/ZhongYeMay/MayOS/32dd4032f9044656cbe4d96bc0a3a6d241d0e520/versions/0.5.4-beta.4-dev/linux/installed/install-firefox
sudo sh ./install-firefox

安装脚本从 GitHub 下载，Firefox 软件包由 APT 从 Debian 签名仓库获取。开发分支构建的基础镜像按需安装 Firefox。下方可下载的 Beta 4 硬盘镜像已经包含 Firefox ESR，可直接从启动台打开。

开发分支构建安装后，Firefox 会出现在启动台和 Dock。浏览器在当前的 Linux64 桌面运行，窗口可还原并拖动边缘调整大小。引导菜单里的 A/B 是同一个 Linux64 系统的升级与回退槽，两个槽共用 /home 中的浏览器配置。切换到尚未安装 Firefox 的槽时可以重新执行安装命令。

创建可启动的 Linux64 硬盘

下载程序会获取约 491 MiB 的根镜像并校验 SHA-256。安装工具生成新磁盘文件，创建时请设置自己的本地管理员密码。

下载安装包获取工具下载安装工具 mayos-linux64-beta4-disk.py文件清单与 SHA-256

在 Debian 或兼容的 Linux 主机安装 Python 3、fdisk、grub-efi-amd64-bin、mtools、dosfstools、e2fsprogs 和 openssl。将下载程序和 mayos-linux64-beta4-disk.py 放到同一目录后执行。

python3 fetch-mayos-linux64-beta4.py
python3 mayos-linux64-beta4-disk.py create --bundle MayOS-0.5.4-beta.4-Linux64-Root.img.gz \
  --sha256 b8a92293fabe887b4c6b43fbae0444453eeb4a0d4517655805c8c730eb3555c3 \
  --output MayOS-Linux64.raw

新磁盘文件的逻辑容量约为 4.1 GiB。QEMU 启动时使用 x86_64 UEFI（OVMF），挂载该文件为原始硬盘，建议分配至少 2 GiB 内存。实体机部署要求空白整盘、512 字节逻辑扇区。当前验收范围是 QEMU，测试时关闭了 Secure Boot。

QEMU 启动命令（Linux 主机）

安装 qemu-system-x86 和 ovmf，确认本机固件路径，再用刚创建的磁盘启动。

cp -n /usr/share/OVMF/OVMF_VARS_4M.fd mayos-vars.fd
qemu-system-x86_64 -machine pc -m 2048 -smp 4 -vga std -boot c \
  -drive if=pflash,format=raw,readonly=on,file=/usr/share/OVMF/OVMF_CODE_4M.fd \
  -drive if=pflash,format=raw,file=mayos-vars.fd \
  -drive file=MayOS-Linux64.raw,format=raw,if=virtio \
  -nic user,model=virtio-net-pci

原地升级和回退

安装完成后，从虚拟终端登录 mayos。升级工具将通过校验的新版写入备用系统分区。用户文件和 Firefox 配置留在独立的 /home 分区。

sudo mayos-linux-update status
sudo mayos-linux-update stage --bundle /path/to/new-root.img.gz --sha256 <发布页的 SHA-256>
sudo reboot
sudo mayos-linux-update confirm

在试启动的新系统中确认后，才会切换默认启动槽。试用后直接重启会返回旧槽。Beta 4 是当前公开的安装镜像，原地升级实录中的 Beta 5 仅用于验收。
