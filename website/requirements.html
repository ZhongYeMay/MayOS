现代 x86‑64 硬件试用

USB 键盘与鼠标

直连 xHCI 根端口的 USB HID Boot Protocol 键盘和相对移动鼠标。QEMU 禁用 PS/2 后，双控制器输入和键盘重连通过。

UEFI 与 NVMe

QEMU Q35/OVMF 已验证 64 GiB 以上的 xHCI 与 NVMe 寄存器、512 字节扇区的冷启动读回，以及从 GPT NVMe 硬盘启动并完成首次设置。

仅内存试用

在 GRUB 选择 Test hardware (RAM only)。退出后不保留本次文件。实测 SATA 与 NVMe 镜像的 SHA-256 均保持不变。

在实体 x86‑64 电脑上试用时，使用 UEFI 启动并关闭 Secure Boot，键鼠直连。进入桌面后按 F1 打开 MayShell，输入 hardware 查看已识别的设备。

正式版 0.5.2 · MayOS Live

Live：直接体验，不向物理磁盘写入

在 BIOS/UEFI GRUB 菜单中选择 MayOS Live 0.5.2。系统使用 RAM-only 会话，创建的临时文件会在关闭后消失。内核底层增加写入拦截；QEMU 在 BIOS 与 UEFI 下验证了使用 Live 前后磁盘 SHA-256 完全一致。

Live 并不安装系统。实体主板、USB 存储控制器、硬件兼容性仍待验证，请优先在 QEMU 中测试。

正式版 0.5.2 · QEMU 实测

离线安装器的测试配置与磁盘限制

处理器与固件

x86_64 64 位处理器；安装 ISO 在 QEMU 中测试 BIOS 与 UEFI x64；安装完成的硬盘目前仅验证 UEFI x64 启动，并需关闭 Secure Boot。

内存与显示

QEMU 安装测试使用 512 MiB RAM、标准 VGA / OVMF framebuffer。图形安装器和串口控制台均通过验证。

目标磁盘

代码要求至少 80 MiB，512 字节逻辑扇区；QEMU 用 96 MiB 空白盘验证。当前允许的磁盘大小上限约 128 GiB（最大 268435455 扇区），不代表实用容量建议。

当前安装器仅接受 /dev/sd[a-z] 或 /dev/nvme[0-9]n[0-9] 形式的非可移动整盘，拒绝分区、只读盘、非 512 字节逻辑扇区与已有内容的目标。安装后需移除 ISO，并由目标硬盘通过 UEFI x64 引导。

仅使用独立空白测试盘
全新安装会对选中的整盘写入 GPT 与 MayOS 镜像。测试请使用专用 QEMU 虚拟硬盘，检查目标盘后再确认。

0.5.3-dev · 开发版本 / 尚未正式发布

自动识别分辨率，最高支持 4K 模式

下一开发版本优先使用显示器与显卡驱动公布的模式，不强制固定 1080p，也不会强制所有显示器使用 4K。范围包括常见 4:3、5:4、16:10、16:9、21:9、32:9、竖屏、3840×2160 UHD 与 4096×2160 DCI 4K；自动选择最长边不超过 4096 像素的可用优先模式。

MayKernel64/Live 通过 GRUB 与固件自动选择 GOP/VBE 模式；Linux64 从已连接的 DRM 模式列表检测并尝试设置 framebuffer。显卡不允许切换时保留固件已启用模式。鼠标与触摸屏坐标随画面比例调整，避免超宽屏和竖屏点击偏移。

限制：目前还是 1280×720 逻辑桌面按比例绘制；尚未支持真正原生 HiDPI 字体排版、热插拔自动重新配置和所有实体显卡显示器组合。此功能没有包含在已发布的 0.5.2 正式 ISO 中。
