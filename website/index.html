Core features

两个启动环境，一套桌面理念。

项目仍处于实验阶段。下列能力来自 MayOS 源码与现有测试记录，不表示兼容所有实体机硬件。

01 / MAYKERNEL

自研系统内核

独立 32 位 x86 内核，支持图形工作区、文件操作、基础内存管理与 MayFS 实验文件系统。

02 / LINUX

真实 Linux 图形模式

独立 x86_64 Linux 内核及用户态桌面，使用 fbdev/evdev 驱动显示和键鼠，含救援终端。

03 / DESKTOP

简洁的桌面窗口

基于 Ubuntu 风格的深紫灰配色、橙色强调色、扁平标题栏和左侧应用 Dock，降低卡通感。

开发快照 · 尚非新 Release

Ubuntu 风格 + Fastfetch + 图形优化

已在 GitHub 当前源码中集成真实 Fastfetch 可执行文件的打包流程、系统信息桥接及新窗口配色。

最新开发改进：Linux XRGB8888 framebuffer 提供逐行复制快路径，非匹配格式保留像素转换。

发布状态：当前网页展示源码开发进度。上述新增内容尚未有单独经过 QEMU 完整验证的公开 ISO；不要将历史下载包视为包含这些变更。
