双内核工作台

通过 GRUB 选择自研 MayKernel 或 Linux 图形环境。现有验证范围是 QEMU、BIOS 与 UEFI x64。

MayFS 文件系统

自研内核使用专用 IDE 数据盘保存文件。Linux 桌面目前使用临时 RAM 文件区，两者尚未共享文件。

清晰的桌面体验

Ubuntu 风格窗口、真实 Fastfetch 信息与 XRGB8888 显示优化，持续改进每一次操作。
