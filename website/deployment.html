INSTALLATION & EXTERNAL BOOT

部署 MayOS。
先测试，再安装。

同一张实验性 ISO 可以从 BIOS 或 UEFI 启动，分别进入 MayKernel64、Linux64 桌面和离线安装器。本指南区分不安装的启动体验与写入硬盘的安装操作。

COMPONENT VERSIONS

镜像中分别包含什么？

MayKernel64

最新已发布原生内核启动预览：0.5.2-pre4。它是从发布 ISO 提取并核对 SHA-256 的启动内核。

Linux64

从 MayOS 当前主分支的 Linux 桌面代码独立编译，内核版本 7.3.1，包含桌面、救援与兼容救援启动项。

离线安装器

复用已发布的 0.5.2-pre2 安装 / 恢复环境。它安装的是 0.5.2-pre2，而不是预览中的 0.5.2-pre4。

版本差异说明
不要把「最新 MayKernel 启动预览」误认为「最新已验证的磁盘安装版本」。组合介质不会自动升级安装器的写盘镜像。任务管理器的 Mission Center 重开发也不包含在此已发布组件中。

获取构建与 QEMU 验证结果现有安装器 0.5.2-pre2硬件要求

只有当 GitHub Actions 显示完整构建和 QEMU 验收成功，且出现真实 ISO 附件或实验性 Release 时，才能下载组合镜像。构建失败、任务仍运行或仅有源码，不代表存在可安装镜像。

STEP 01

先验证下载文件

下载 ISO 与同一构建提供的 SHA256SUMS.txt。对比哈希必须一致，且文件名必须对应同一次构建。Windows 可以使用 PowerShell：

Get-FileHash .\MayOS-0.5.2-pre4-DualKernel-Installer-x86_64.iso -Algorithm SHA256

Linux：

sha256sum -c SHA256SUMS.txt

macOS：

shasum -a 256 MayOS-0.5.2-pre4-DualKernel-Installer-x86_64.iso

如果哈希不一致，停止使用。不要将不同版本的安装器、启动 ISO 和校验清单混用。

STEP 02 · RECOMMENDED

使用 QEMU 测试

建议使用 1 GiB 或更多 RAM 的 QEMU x86_64 虚拟机，标准 VGA。以下命令仅创建并使用本地虚拟硬盘文件，不操作实体磁盘；请在镜像所在目录执行：

qemu-img create -f raw mayos-test.img 128M
qemu-system-x86_64 -m 1024 -vga std -cdrom MayOS-0.5.2-pre4-DualKernel-Installer-x86_64.iso -boot d -drive file=mayos-test.img,format=raw,if=ide

GRUB 菜单里，Start MayKernel64 进入原生系统，Start Linux64 进入 Linux 桌面；还可以选择救援模式或 Install MayOS 0.5.2-pre2。仅浏览桌面不需要选择安装器。

UEFI 测试需要 OVMF 固件。以下路径是部分 Linux 发行版的示例，以本机安装的实际 OVMF 路径为准：

cp /usr/share/OVMF/OVMF_VARS_4M.fd ./mayos-uefi-vars.fd
qemu-system-x86_64 -m 1024 -vga std -cdrom MayOS-0.5.2-pre4-DualKernel-Installer-x86_64.iso -boot d -drive file=mayos-test.img,format=raw,if=ide -drive if=pflash,format=raw,readonly=on,file=/usr/share/OVMF/OVMF_CODE_4M.fd -drive if=pflash,format=raw,file=mayos-uefi-vars.fd

STEP 03 · EXTERNAL MEDIA

从 U 盘或外置光驱启动

若要从另一台电脑或外置设备启动，可将已校验的 ISO 制作为专用启动 U 盘，或通过支持的外置光驱刻录/加载光盘映像。建议先用 QEMU 完成验证。

  1. 准备一只没有重要数据的专用 U 盘。制作启动盘会清除该设备原有内容；不要选择存储资料的硬盘。
  2. 在 Windows 可使用 Rufus，在 Windows/macOS/Linux 可尝试 balenaEtcher。选择正确的 .iso 和目标 U 盘；只有工具明确支持镜像写入模式时才进行写入。不要仅把 ISO 当作普通文件复制到 U 盘。
  3. 插好 U 盘后重启电脑，通过主板的启动设备选择菜单（不同厂商可能是 F12、F11、Esc 或其他按键）选择对应的 UEFI: USB 或外置设备。
  4. 关闭 Secure Boot，检查是否看到 GRUB 中的 MayKernel64、Linux64 和安装器选项。优先选择非安装项进行兼容性检查。

兼容性边界：已验证的 BIOS/UEFI 启动主要是 ISO 在 QEMU 虚拟光驱中的测试。实体主板的 U 盘原始镜像引导、USB 控制器兼容性和固件行为尚未普遍验证；无法启动时不要修改内部硬盘来尝试修复。

STEP 04 · INSTALLER

离线安装到空白测试盘

安装器是会修改磁盘分区表和文件内容的程序，不是只读试用模式。请选择专用、空白、可舍弃数据的虚拟磁盘作为测试目标。图形安装或串口控制台安装均需要明确选盘并再次确认。

QEMU 演示中可使用新建的 128 MiB 虚拟硬盘；安装器要求至少 80 MiB、512 字节逻辑扇区的受支持整盘。安装完成后关闭虚拟机，移除 ISO，只从新安装的虚拟硬盘启动并进行首次设置。不要将此流程直接套用到存放个人文件的实体硬盘。

外置 USB 存储设备可能被系统标记为 removable，安装器会拒绝这类目标。能从 U 盘启动安装器，不代表允许把 MayOS 安装到 U 盘。

实体电脑安装尚未达到正式验收
目前不保证所有 SATA/NVMe、USB 桥接设备、4Kn 扇区、显卡、键鼠、UEFI 固件及断电恢复兼容。不要在主力电脑或有数据的实体硬盘上执行安装、升级、回滚实验。正式发布前需要专门的硬件兼容性测试。
