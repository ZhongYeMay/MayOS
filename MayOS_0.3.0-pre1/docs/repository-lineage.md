# 仓库中的历史版本与本实验版本

`ZhongYeMay/MayOS` 保留多条开发记录。本次把现有 `MayOS 0.3.0-pre1` 项目整理到独立目录，方便下载、构建与查看发布记录；不覆盖历史版本。

| 目录 | 定位 |
| --- | --- |
| `MayOS_0.1_Eng` | 历史 16 位 MayOS 版本线，保留原有代码与说明 |
| `MayOS_0.2_Eng` | 历史 16 位 MayOS 版本线，保留原有代码与说明 |
| `MayOS_0.3.0-pre1` | 本次实验性的现代桌面版本：自研 x86 32 位内核，以及可独立启动的 Linux 7.3.1 x86_64 图形环境 |

目录中的版本编号用于区分发布记录，不自动表示不同版本之间存在直接源码演进关系，也不表示可执行文件、磁盘格式或启动协议相互兼容。请分别按照各目录的说明构建与运行。

本版本使用 GRUB 在 BIOS 或 x64 UEFI 下启动；UEFI x64 指 EFI 引导程序架构，自研 MayKernel 仍为 32 位。Linux 模式的桌面是实际用户态进程；其桌面文件保存在进程 RAM 中。完整支持范围与验证记录见本目录的 README 和发布说明。

## 源码与发布附件

仓库目录保存第一方源码、文档、必要图片资源及第三方许可通知。启动 ISO、虚拟磁盘、编译缓存、录像和完整第三方源码归档作为 Release 附件分发，不进入本目录的源码历史。

本次整理没有修改既有授权，也没有为新目录新增许可证。仓库根目录的历史 MIT 许可文件保持原状，本次没有将其复制到此目录或据此对本实验版本作重新授权声明。第三方组件继续遵循其原有许可；具体来源与通知见 [第三方组件说明](third-party/dual-boot.md)。
