# MayOS 版本与历史说明

`MayOS_0.3.0-pre1/` 是当前实验桌面源码目录，包含自研 32 位 x86 MayKernel 及独立的 Linux x86_64 图形运行环境。BIOS / x64 UEFI 由 GRUB 管理；自研内核并非 64 位。详情参见 [构建说明](../README.md) 与 [第三方组件文档](third-party/dual-boot.md)。

## 旧版本

`MayOS_0.1_Eng/` 与 `MayOS_0.2_Eng/` 属于早期 16 位实验版本，现已从仓库最新工作树删除。它们仍保存在既有 Git 提交历史中，需要查阅时请使用 GitHub 提交记录或 `git log --all -- <path>`。本次整理不改写历史、删除已有提交或追溯清除 Git 对象。

版本号只是发布区分，不代表可执行文件、数据盘格式或启动协议互相兼容。不要使用早期镜像作为当前桌面的启动程序。

## 源码与附件

当前 Git 工作树保存第一方源码、文档、必要媒体素材及第三方许可通知。可启动 ISO、编译产物、录像与对应第三方源代码包应以**实际成功发布**的 Release 附件为准；不可将配置好的自动发布脚本等同于已上传的附件。

本次删除没有更改原仓库 LICENSE，也没有给当前实验版本另行授予新许可。第三方组件各自保留原有许可证。
