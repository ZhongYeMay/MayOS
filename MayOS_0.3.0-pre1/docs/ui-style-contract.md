# MayOS 桌面设计契约：macOS 桌面布局 + Google Material Design 3

**以用户提供的 1024×768 截图 `IMG_5904.png` 为准。**

- **桌面默认状态：** 无任何打开的窗口；顶部深色菜单栏约 42px；
  从左到右为 `MayOS / 文件 / 窗口 / 应用 / 终端`，右侧为时钟、
  网络、系统、通知、电源、设置符号。
- **桌面元素：** 左上 `Notes.txt` 文本文件快捷图标；深色低对比背景
  与五条由左向右逐渐下降的细竖线。双击图标必须打开 MayFS 中的真实文件。
- **Dock：** 底部中央暗色圆角浮动条，六个图标依次为应用、文件、
  设置、终端、文档编辑器、Explorer。图标需真正操作应用而不是静态装饰。
  应用菜单仍能打开回收站与 MayKernel 原生游戏，不得因为删除左工具栏而丢功能。
- **窗口风格：** 继续使用原有 Material Design 3 圆角、文字、图标及
  主题颜色；窗口移动、最大化、关闭、文件管理器、编辑器、MayShell、
  设置、MayFS 持久化必须保留。
- **指针：** 默认黑色方块，白色方块和 `Documents/Cursor.ppm`
  的有界 P3 自定义图片可选；不得恢复未经用户请求的大箭头指针。
- **个性化选项：** 深浅色、六种主题色、高对比度、桌面背景和
  指针大小、桌面版本标识、恢复默认均保留。默认背景对应参考截图。
  每次启动的桌面不能自行弹出设置窗口。
- **验收要求：** 不仅编译通过；还须在 QEMU 用屏幕截图验证顶栏、
  Dock、背景和 Notes 图标位置，并使用模拟鼠标测试所有图标；
  修改后录制实际视频，禁止将预览视频冒充真实操作录屏。

凡需要调整视觉样式的改动，必须以用户明确说明或再次确认的设计为准；
功能性更改不构成重新设计用户界面的授权。
