# MayOS 原有用户界面样式保留规则

**默认界面样式只能在用户明确要求修改后更改。** 这包括默认窗口排布、Material 3 控件、边框圆角、字体、桌面布局、主题色和导航交互。功能开发不得顺带重做界面。

## 本次更改的允许范围

- 以 PR #9 之前的 `main` 默认外观为基准：原有工作区、文件管理器、终端、编辑器、设置面板以及前四个设置栏目均保留。
- 之前新增的功能保持可用：浅/深色、6 种主题色、高对比、3 种桌面背景、3 档指针大小、桌面版本标识以及 MayFS 设置保存。它们由用户主动选择；冷启动默认仍是原来的深色 Material 工作区。
- **唯一明确授权的默认视觉变化是鼠标指针。** 默认指针换成黑色实心正方形（白色细边），另可选白色正方形（黑色细边）。
- “自定义图片”按钮读取 **Documents/Cursor.ppm**，仅支持文本 PPM **P3**、RGB `255`、最大 **16×16**、文件不超过 MayFS 单文件限制；洋红色 `255 0 255` 被视为透明像素。为新建的 MayFS / Linux RAM 会话提供可编辑样例；已有数据盘可以在文档目录手动创建同名文件。其他格式（PNG/JPG/BMP）暂未实现，不得声称支持。
- 无效图片不会破坏当前指针；如果保存的自定义文件失效，启动时安全回退到黑色方块。MayKernel 的选择保存在原有校验记录中，兼容之前的设置记录。
- 颜色、字号、窗口几何、字体和通用控件实现不得未经许可改变。新设置仅沿用原来的 `button`、`text` 等控件，不创建第二套主题。

## 自定义图片示例

可在内置文本编辑器打开 `Documents/Cursor.ppm`，修改以下简化示例（每行像素依次排列）：

```ppm
P3
2 2
255
255 0 255    0 0 0
255 255 255  20 184 166
```

保存后，在“设置 → 桌面与指针”选择一次“自定义图片”即可重新加载。MayOS 不自动执行图片格式转换。

## 回归门槛

`python3 scripts/test_ui_style_contract.py` 检查 PR #9 之前原有 `rect`、`border`、`roundrect`、`circle`、文字、按钮、窗口框架代码以及默认 Material 色彩。实际启动和鼠标点击等仍应以 QEMU 验证为准。视频必须是对应构建的真实 QEMU 操作录屏，不得拿离线页面预览或旧录像代替测试证明。
