## 网络

| 能力 | MayKernel | Linux 7.3.1 |
| --- | --- | --- |
| 网卡 | QEMU RTL8139 PCI IO 端口驱动 | Linux e1000 内核驱动 |
| DHCP、IPv4、ARP | 原生实现 | Linux + BusyBox |
| ICMP ping | 原生 Echo 到网关 | BusyBox ping |
| DNS A 记录 | 原生 UDP DNS 测试 | Linux resolver / BusyBox nslookup |
| HTTP 文本预览 | 原生 TCP/HTTP/1.0（IPv4 字面地址） | Linux socket HTTP/1.0（主机名和 IPv4） |
| HTTPS/TLS、完整 HTML 浏览器 | 不支持 | 不支持 |
| Wi-Fi、实体网卡普适驱动 | 不支持 | 不在已验证配置内 |
| TCP 泛用 socket API | **不支持**；只实现一个异步 HTTP 请求客户端 | 由 Linux 提供 |

MayKernel `net`、`net ping`、`net dns`、`net renew` 可从 MayShell 访问。
原生 Explorer 已通过 QEMU NAT 到本机测试 HTTP 服务器实测真实 TCP 响应。
Linux 模式保留 DHCP、DNS、HTTP 预览以及 Linux 串口 shell 的 BusyBox 工具。

## 文件系统和数据安全

- MayKernel：MayFS ATA 数据盘格式，支持持久化与冷启动验证。
- Linux 桌面：内存会话临时数据；**不会自动挂载或修改 MayFS 磁盘**。
- 两者 GUI 交互相同，但底层文件持久化策略不同。不会用
  “两个内核功能完全一致”误导用户。

## 发布门槛

1. 0.4.0 原生 ISO 构建、GUI/文件系统回归、RTL8139 + DHCP/Ping/DNS +
   真实 TCP/HTTP 测试全部通过。
2. Linux 7.3.1 双内核 ISO 构建与 BIOS 测试全部通过。
3. OVMF UEFI 两条启动路径与救援系统测试通过。
4. 记录 ISO SHA-256，与下载文件校验匹配。
5. 对应 Linux、BusyBox 等第三方许可证及源码供应条件满足。

只有所有门槛通过，才能发布标记为正式版的 v0.4.0。
当前只验证 QEMU x86/x86_64，不能推断已经支持 Secure Boot、手机、
ARM、任意物理电脑或日常生产用途。
